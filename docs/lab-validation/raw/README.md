# Laboratory evidence

Raw output of the laboratory validation runs (`../run-lab-validation.sh`) and
of the node diagnosis (`../diagnose-cluster.sh`), as produced on the cluster.
The report `../INFORME_VALIDACION_LAB.md` lists every run and what it covers.

The only edit made to these files before publication: the public IP addresses
of the nodes are replaced by `<ip-kb2>`, `<ip-worker1-kb2>` and
`<ip-edgenode01>`. Pod and service addresses (private ranges) are unchanged.
No Secret value is recorded by the scripts.
